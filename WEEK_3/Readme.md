## 🧠 Overview

The objective of this project is to **predict carbon emissions** using machine learning models. After cleaning and refining the dataset, this week we made significant progress by using `data_cleaned.csv` to build and evaluate our **first predictive model**.

---

## ✅ Week 3 Implementations

### 📂 1. Utilized Cleaned Dataset (`data_cleaned.csv`)
- Transformed raw Kaggle dataset into a cleaned, structured format
- Removed null values, handled outliers, standardized column names
- Prepared the dataset specifically for modeling and visualization tasks

### 📊 2. Feature Correlation & Selection
- Analyzed feature relationships with target variable `co2_ttl`
- Generated correlation matrix and bar charts
- Identified top contributing features to carbon emissions

### 🧠 3. First Model: Linear Regression
- Trained a **Linear Regression model** using cleaned data
- Split data into training and testing sets
- Evaluated model performance using R² score and MAE/MSE
- Visualized prediction accuracy using scatter plots

### 📈 4. Insightful Visualizations
- Bar graphs for correlation strength
- Line plots to show emission trends over years
- Feature-target comparisons to improve interpretability
